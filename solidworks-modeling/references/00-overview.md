# 00 · 总览：把「建模意图」变成可执行的调用序列

## 这个技能解决什么问题

用户说「帮我建一个 m=2 z=55 的直齿圆柱齿轮，齿宽 20，中心孔 20 带键槽」——
这句话要变成 SolidWorks 里一串正确顺序的 API 调用。中间有三道坎：

1. **几何坎**：渐开线齿廓怎么算（齿数、模数、变位、根切、齿顶变尖）
2. **接口坎**：SolidWorks 的 1.4 万个 API 方法里，哪几个、按什么顺序、参数是什么
3. **顺序坎**：先选面还是先画图？什么时候必须关草图？阵列选哪个 mark？

本技能把三道坎拆成三层，各管一段：

```
用户的话
   │
   ├─ 几何层  scripts/sw_gear.py      参数 → 毫米坐标点（纯数学，可离线测）
   │            involute / 标准件尺寸表 / 根切校验
   │
   ├─ 顺序层  plan JSON + sw_plan.py  「先干什么后干什么」声明式表达 + 离线校验
   │            op 的 requires/effect 组成状态机
   │
   └─ 接口层  scripts/sw_ops.py       一个 op → 一串确定的 API 调用
               带参数顺序、单位换算、枚举名、选择 mark、清理动作
```

**关键设计**：三层里只有最底下那层需要 SolidWorks 在场。几何和顺序都能离线跑、
离线测。所以「训练」这个技能的大部分工作不用开软件，一秒一轮。

## 两条路线，先选对再动手

| | A. 从零建模 | B. 参数化改型 |
|---|---|---|
| 场景 | 没现成模型，或要生成一整个族 | 已有 .SLDPRT，只改尺寸 |
| 做法 | 写 plan，用 sketch/feature 系列 op 一步步建 | `open` → `list_dimensions` → `set_dimension` |
| 速度 | 慢（几十秒到几分钟） | 快（改几个尺寸重建即可） |
| 稳定性 | 中（依赖草图轮廓正确） | 高（几何关系已存在） |
| 什么时候用 | 新零件；要生成 N 个规格 | 用户手里有零件库（本机 `C:\学习软件\一级减速器\` 就是）|

**判断规则**：用户给了具体零件文件路径 → 走 B；用户只给了参数或图纸 → 走 A。
B 路线一定先用 `list_dimensions` 打印真实尺寸名，**不要猜** `D1@Sketch1@xxx.SLDPRT`。

## 调用顺序总则（跨所有零件成立）

这是踩坑之后稳定下来的骨架。任何 plan 基本都长这样：

```
new_part                        建文档（必须第一步；模板不对会弹框卡死）
select_plane(Front)             选基准面
sketch_begin                    进草图（此后所有图元命令都在草图里）
  ...画图元：line / circle / spline / arc3p / rect_center...
sketch_end                      出草图（必须！不关草图画不出特征）
extrude_boss / extrude_cut      做特征（此时选中草图）
rebuild                         重建，尽早暴露约束冲突
...再开草图 → 切除 → 倒角/圆角 → 阵列...
                                ★ 例外：圆角要吃的那条边，不能在它之后被别的切除打断（铁律 5）
check_*                         校验（包围盒/质量/特征数）
save_as                         落地
```

五条铁律：

1. **一个草图只能养一个特征**。同一个草图重复拉伸会得到「同一个轮廓的多个实例」，
   通常不是你要的。要切除就新开一个草图。
2. **特征依赖选择集**。SolidWorks 的特征 API 不是「把轮廓对象传进去」，而是
   「先选中东西，再调用方法」。所以每个特征 op 内部都先 `SelectByID2`，
   并且必须用对 **mark 号**（见下文）。
3. **每个 op 结束都要清选择 + 关 AddToDB**。选择是隐式全局状态，留着会污染下一个特征。
4. **拉伸深度、草图坐标、偏移距离，SolidWorks 内部一律是米**。
   本技能的 op 参数一律**毫米**，换算在 op 内部做。不要自己再乘 1000。
5. **顺序：先建「要靠它取边」的特征，再切「会打断这条边」的槽/孔**（坑表 §109⑥）。
   例：Ø34 孔口要倒 R8，就必须**先倒圆角、后切键槽** —— 键槽先切会把孔口整圆切成两段弧，
   而两段弧的「中点」会退化成「两端点平均」、**完全相同**，圆角永远选不中、反复报「重建失败」。
   凡「圆角/取边反复失败」，**先怀疑顺序，再怀疑几何**：
   造一个「去掉打断特征」的对照模型单独测一遍，即可定性（对照成功 ⇒ 是顺序，不是几何）。

## 选择 mark 速查（记错就是「无效的参考」）

| 操作 | 谁 | mark |
|---|---|---|
| 拉伸/旋转/切除 | 轮廓草图 | 0 |
| 圆周/线性阵列 | 种子特征 | 4 |
| 圆周/线性阵列 | 方向参考（轴/边） | 1 |
| 线性阵列 | 方向 2 | 2 |
| 镜像 | 要镜像的特征 | 4 |
| 镜像 | 镜像面 | 2 |
| 旋转 | 中心线/轴 | 1 |

`sw_connect.SwSession.select()` 和 `sw_ops._select_feature()` 已经把 mark 参数化了。

## 常见零件的推荐路径

| 零件 | 推荐做法 | 关键 op |
|---|---|---|
| 直齿/斜齿圆柱齿轮 | 整圈渐开线轮廓一次画完 → 拉伸 | `gear_profile` → `extrude_boss` |
| 阶梯轴 | 半剖面 + 中心线 → 旋转 | `line`/`centerline` → `revolve_boss` |
| 圆板法兰 | 外圆拉伸 → 挖内孔 → 螺栓圆草图阵列 → 切除 | `circle` → `extrude_cut` → `sketch_circular_pattern` |
| 六角头螺栓 | 六边形拉伸 → 圆杆拉伸 → 头部倒角 | `polygon` → `extrude_boss` → `chamfer` |
| 箱体/端盖 | 外形拉伸 → 抽壳 → 挖孔 | `extrude_boss` → `shell` → `extrude_cut` |
| 键槽（毂上） | 孔草图里加矩形 → 与孔一起切除 | `rect_center` + 同草图 `circle` |
| 改动已有零件 | 不要重建 | `open` → `list_dimensions` → `set_dimension` |

关于齿轮为什么**不**用「画一个齿 + 圆周阵列」：相邻齿廓会共用边界，SolidWorks
判定轮廓粘连/开放，拉伸经常失败。整圈一次成形最稳，代码也已验证过点序闭合。
（草图级阵列 `sketch_circular_pattern` 留给「一个孔阵列出 6 个」这类局部场景。）
